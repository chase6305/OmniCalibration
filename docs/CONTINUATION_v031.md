# v0.3.1 续算优化验证

本轮保留 v0.3.0 的 400 次主评估、补充数据和复现包，不用新结果替换旧的未接受记录。目标是在残差、覆盖率、界限和局部可观测性均合格而外迭代尚未稳定时，先继续当前估计，减少重新探索相机初值。

## 续算机制

- 新增 `local_continuation` 参数，默认启用；它与相机全局重试 `allow_restarts` 分开控制。严格复现旧的无续算路径时显式设 `local_continuation=False`。
- 续算只处理内层成功、噪声/覆盖率一致、未触界限、满秩且满足声明 sigma 限制的候选。原数据、模型、噪声、损失与对应点规则不变。
- 从末次关节零偏、相机 Lie 修正和可选对数尺度开始。局部步长不大于 0.25，保持最终裁剪与噪声层；不重新初始化相机。
- 每个候选最多追加一次续算。续算内部禁用再次续算和相机重试；相机重试产生的候选也有一次续算机会。
- 接受条件保持不变，停止仍检查完整拟议步长，不能以缩小后的步长伪造稳定。
- 成功轨迹累计原阶段与续算的 history、iterations 和 all_inner_success，区分 phase。未完成续算也保留历史与质量标志。

`outer_iterations` 仍是每次关联求解阶段的上限，并非整个重试工作流的总上限。续算失败可能增加耗时，不能假定所有数据都加速。`history` 对被选中的原阶段和成功续算合并；相机重试的其他候选保存在 initialization 的重试记录中。

## 验证计划

最终数值源固定在 `outputs/continuation_frozen_v031.json`。成对开发实验使用 `configs/benchmark_continuation_paired_v031.json`，同源码、同场景、同种子 12005/12014，仅切换续算开关。独立验证使用 17001–17004 新种子、七个场景，共 28 次，包含左右单臂、双臂、共享编码器噪声、尺度离群点、无锚定退化与距离平方噪声压力场景。

先前只在相机重试之前续算的原型，没有解决 seed 12005 的未停止，相关记录在 `outputs/continuation_development_v031`；16001–16004 的 24 次原型验证也独立保留。它们不与最终源码的验证混合。

## 验证结果

82 项测试通过。成对四次与独立 28 次记录通过源码、输入、残差汇总、接受条件与资产哈希审计。

| seed | 关闭：接受/重试/耗时 | 启用：接受/重试/耗时 |
|---|---|---|
| 12005 | 否 / 6 / 352.8s | 是 / 1 / 127.5s |
| 12014 | 否 / 6 / 368.4s | 是 / 1 / 128.5s |

这是两个历史开发案例的描述性成对结果，不构成任意数据上的加速保证。两组的接受规则与完整步长停止条件一致，未根据真值选择初值或放宽门限。

独立四个新种子 × 七种场景：24 个预期可观测案例全部接受，4 个无锚定单臂案例全部保留；各场景最坏关节误差见下表。退化参数不唯一，不统计精度。
